# Glossary — Dakhotiyapi Vocabulary

All vocabulary introduced in this course, alphabetical. **STV** = Stative Verb (acts as adjective), **VAI** = Active Intransitive Verb, **VT** = Transitive Verb, **N** = Noun, **PART** = Particle/Phrase.
