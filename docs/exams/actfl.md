# ACTFL Proficiency Reference — Dakota

## Proficiency Level Descriptions

### Novice Low (Target: End of Chapter 2)
| Mode | Description |
|------|-------------|
| Speaking | Isolated words: *Háu/Haŋ*, *Pidámayaye*, numbers 1–10 |
| Writing | Isolated words; name and greeting |

### Novice Mid (Target: Mid-Year / Chapters 3–4)
| Mode | Description |
|------|-------------|
| Speaking | Memorized phrases; basic sentences using SOV order; daily activities |
| Writing | Short sentences; can use *-kte* (future) and *-šni* (negation) |

### Novice High (Target: End-of-Year / Chapters 7–8)
| Mode | Description |
|------|-------------|
| Speaking | Short spontaneous phrases; can describe seasons, land, and values |
| Writing | Short paragraphs; past and future tense; connected sentences |

### Intermediate Low (Stretch Goal)
| Mode | Description |
|------|-------------|
| Speaking | Simple narration; can discuss treaty history and Dakota values in context |
| Writing | Connected paragraphs; multiple tenses; conveys meaning despite errors |

---

## Self-Assessment Rubric

=== "Speaking"
    | Level | I can... |
    |-------|----------|
    | Novice Low | Say *Háu/Haŋ*, count to 10, give my name |
    | Novice Mid | Describe daily activities using SOV sentences |
    | Novice High | Talk about seasons, values, and the land |
    | Intermediate Low | Narrate a short story or describe treaty history |

=== "Writing"
    | Level | I can write... |
    |-------|----------------|
    | Novice Low | Isolated Dakota words correctly spelled |
    | Novice Mid | Short SOV sentences with future and negation |
    | Novice High | Short paragraphs on familiar topics |
    | Intermediate Low | Connected paragraphs using multiple tenses |

## Exam Score Interpretation

| Score | ACTFL Estimate |
|-------|---------------|
| 90–100 | Novice High / approaching Intermediate Low |
| 75–89 | Solid Novice High — met year-end target |
| 60–74 | Novice Mid–High — some gaps remain |
| Below 60 | Novice Low–Mid — significant review needed |
