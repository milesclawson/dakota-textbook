## Dakota Grammar — Key Features

!!! note "SOV Word Order"
    Dakota is a **Subject-Object-Verb** language — the verb comes at the end. "I eat bread" becomes "I bread eat" in Dakota structure. This is one of the biggest adjustments for English speakers.

!!! note "Future Tense with *-kte*"
    The future tense in Dakota uses the suffix **-kte** at the end of the verb: *mduté* (I eat) → *mduté kte* (I will eat). This contrasts with Ojibwe, which uses a prefix (*inga-*).

!!! note "Stative Verbs"
    Many Dakota "adjectives" are actually stative verbs — they describe a state of being. "The dog is black" uses a verb meaning "to be black," not an adjective modifying a noun.
